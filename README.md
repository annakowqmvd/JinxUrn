# JinxUrn

JinxUrn enables event-driven, distributed applications with auto-scaling and load powered by a robust, real-time manager and scalable engine.

The key benefits of using JinxUrn include:

- JinxUrn enables event-driven, distributed applications
- with auto-scaling and load powered
- by a robust, real-time manager

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/JinxUrn.git`
2. `cd JinxUrn`
3. Install in editable mode: `pip install -e .`

## Configuration

JinxUrn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
